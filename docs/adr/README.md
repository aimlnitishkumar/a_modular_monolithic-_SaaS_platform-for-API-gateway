# Architecture Decision Records

This folder captures the architectural decisions for MeterFlow.

## ADR index

- [ADR-0001: Modular monolith as the initial architecture](./0001-modular-monolith.md)

## Why ADRs matter

The platform is a SaaS billing and API gateway product with strong security, tenancy, and reliability requirements. These decisions must remain explicit so future engineering teams understand why the system is structured this way.
